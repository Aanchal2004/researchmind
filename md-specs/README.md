# ResearchMind

AI-native research workspace for discovering, synthesizing, and organizing academic knowledge.

ResearchMind combines multi-source academic retrieval, grounded AI synthesis, citations, collections, and alerts into a modern research UI.

## Current State
- Frontend is nearly complete
- Backend is next
- Architecture is MCP-native and agent-driven

## Core Flow
User query -> Search Agent -> Retrieval tools -> Synthesis Agent -> Citation Agent -> UI response
