# Backend Plan

## Phase 1: Contracts
- Freeze frontend data shapes
- Define TypeScript interfaces
- Define request/response schemas

## Phase 2: Skeleton
- Create FastAPI project
- Add config, logging, CORS
- Add route modules

## Phase 3: First Live Search
- Implement arXiv integration
- Normalize responses
- Connect frontend search

## Phase 4: Multi-source Retrieval
- Add Semantic Scholar, PubMed, Crossref, Unpaywall
- Deduplicate and rank results

## Phase 5: Agents
- Add Search Agent
- Add Synthesis Agent
- Add Citation Agent

## Phase 6: Storage
- Add Supabase schema
- Add auth
- Add collections and alerts

## Phase 7: Hardening
- Add Redis caching
- Add retries and fallbacks
- Add background jobs and monitoring
