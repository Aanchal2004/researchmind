# MCP and Agents

## Agents
- Search Agent
- Synthesis Agent
- Citation Agent
- Alert Agent

## Suggested MCP Tool Names
- search_arxiv
- search_semantic_scholar
- search_pubmed
- lookup_crossref
- resolve_open_access
- get_related_papers

## Rules
- Search Agent only retrieves and ranks.
- Synthesis Agent only summarizes grounded results.
- Citation Agent only formats references.
- Alerts run on a schedule and compare old vs new results.
