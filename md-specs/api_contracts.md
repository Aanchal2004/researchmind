# API Contracts

## POST /api/search
Search academic sources and return ranked results plus synthesis.

## GET /api/papers/{id}
Return paper detail data.

## GET /api/papers/{id}/citations
Return citation formats.

## POST /api/collections
Create a collection.

## GET /api/collections
List collections.

## POST /api/alerts
Create a topic alert.

## GET /api/alerts
List alerts.

## POST /api/auth/login
Login.

## GET /api/me
Return the current user.
