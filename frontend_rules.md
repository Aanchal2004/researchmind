# Frontend Rules

## Framework
- Use Next.js App Router
- Use TypeScript strictly
- Use functional React components

---

## Styling
- Tailwind CSS only
- Use shadcn/ui where useful
- Dark mode default
- Avoid bright gradients
- Avoid glassmorphism overuse
- Use clean spacing
- Use subtle borders

---

## Design Style
- Modern academic
- Think:
  - Linear
  - Perplexity
  - Notion
  - GitHub dark
- Dense but readable
- High signal-to-noise ratio

---

## Components
Build reusable components:
- Sidebar
- Navbar
- SearchBar
- ResultCard
- PaperCard
- CitationBadge
- CollectionCard
- SynthesisPanel
- LoadingSkeleton

---

## Typography
- Strong hierarchy
- Large bold headings
- Compact metadata text
- Monospace only for tags/code

---

## Layout
- Responsive
- Mobile-first
- Max content width
- Sticky navigation

---

## Animations
- Very subtle
- Prefer Framer Motion
- Avoid flashy effects

---

## Code Quality
- Reusable components only
- Avoid duplication
- Use clean folder structure
- Keep logic separate from UI

---

## Accessibility
- Keyboard navigable
- Proper semantic HTML
- Focus states
- Good contrast

---

## DO NOT
- Do not use inline styles unless necessary
- Do not hardcode layout values repeatedly
- Do not generate giant monolithic components
